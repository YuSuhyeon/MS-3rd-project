### [Klover - 외국인 관광객 맞춤형 서울 여행 플랫폼 기획 및 개발]

외국인 관광객의 언어 소통, 관광 정보 탐색, 이동 과정에서 발생하는 불편을 해결하기 위해 AI 기반 서울 여행 플랫폼 ‘Klover’를 기획·개발했습니다. 사용자 여정 관점에서 여행 정보 탐색, 관광지 안내, 메뉴판 해석 등 실제 여행 상황별 Pain Point를 정의하고 기능 우선순위를 도출했습니다. 이후 Azure OpenAI와 RAG 기반 실시간 여행 정보 Q&A 챗봇, YOLOv8 기반 관광지 이미지 인식 및 AI 도슨트 기능, Azure OCR·Translator 기반 메뉴판 분석 및 실시간 번역 기능 등을 설계·구현했습니다. 또한 사용자 흐름을 고려해 관광 정보 탐색부터 번역·추천 기능까지 연결되는 서비스 구조를 구성하며 AI 기술이 실제 사용자 경험 개선으로 이어질 수 있도록 기획했습니다.
