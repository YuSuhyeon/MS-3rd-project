# 서울 관광지 페르소나별 여행 코스 데이터

**작성일**: 2025년 9월 8일  
**프로젝트**: 서울 POI 기반 페르소나별 여행 코스 최적화

## 📋 프로젝트 개요

이 프로젝트는 6가지 관광객 페르소나별로 맞춤형 서울 여행 코스를 제공하는 데이터셋입니다. 각 페르소나의 특성과 예산에 맞는 장소들을 선별하여 최적화된 여행 경로를 구성했습니다.

## 👥 페르소나 분류

| 페르소나 ID | 페르소나명 | 예산 | 주요 특성 |
|------------|-----------|------|----------|
| 0 | 알뜰 필수코스 정복자 | $1,000-2,000 | 한국 첫 방문, 필수 코스 중심 |
| 1 | 플렉스 장기 체류객 | $3,000+ | 프리미엄 여행, 장기 체류 |
| 2 | 관계 중심 체류객 | - | 친구/친지 만남 중심 |
| 3 | 실속파 쇼핑 원정대 | $1,000-2,000 | 쇼핑 집중, 재방문객 |
| 4 | 문화유산 탐험가 | $2,000-3,000 | 고궁, 역사 유적지 중심 |
| 5 | 미니멀 K-컬처 팬 | $1,000 이하 | K-POP, 한류 문화 중심 |

## 📁 파일 구조

### 주요 데이터 파일
- `itineraries_all.csv` - 전체 페르소나 통합 일정 데이터
- `routes_all_simplified.csv` - 전체 페르소나 통합 경로 데이터 (간소화)
- `수동_서울POI_페르소나매핑.csv` - 원본 POI-페르소나 매핑 데이터

### 페르소나별 개별 파일
- `routes/persona_0_알뜰 필수코스 정복자.csv`
- `routes/persona_1_플렉스 장기 체류객.csv`
- `routes/persona_2_관계 중심 체류객.csv`
- `routes/persona_3_실속파 쇼핑 원정대.csv`
- `routes/persona_4_문화유산 탐험가.csv`
- `routes/persona_5_미니멀K-컬처팬.csv`

### 스크립트 파일 (5개)
- `scripts/split_persona_routes.py` - **페르소나별 파일 분할**
  - `routes_all_simplified.csv`를 읽어서 페르소나별 개별 CSV 파일 생성
  - 각 페르소나의 고유한 여행 코스 데이터 추출
  - 데이터 일관성 검증 및 파일 구조 확인
- `scripts/validate_current_routes.py` - **현재 데이터 검증**
  - 좌표 누락 장소 확인 및 리포트
  - 서울 지역 범위 내 좌표 검증 (위도: 37.4-37.7, 경도: 126.7-127.2)
  - 페르소나별 파일 구조 및 데이터 완성도 검사
- `scripts/analyze_routes_data.py` - **데이터 분석 및 통계**
  - 페르소나별 장소 수, 코스 수 등 통계 분석
  - 지역별 분포 및 장소 유형 분석
  - 데이터 품질 및 완성도 평가
- `scripts/test_current_api.py` - **API 연결 테스트**
  - 카카오맵 API 연결 및 권한 확인 (401/403 오류 감지)
  - OpenStreetMap 지오코딩 테스트
  - API 키 유효성 검증 및 대안 제시
- `scripts/update_routes_with_sort.py` - **데이터 업데이트 및 정렬**
  - `routes_all_simplified.csv` 데이터 수정 및 업데이트
  - 페르소나ID, 일차, 코스ID, 구간순서 기준 자동 정렬
  - 페르소나별 파일 자동 재생성

### 웹 애플리케이션 통합용 파일
- `web_map/map-app/` - React 기반 지도 시각화 앱
- `test_persona_routes.html` - 독립형 HTML 지도 시각화 (카카오맵 API 연동)

## 🗺️ 데이터 구조

### 일정 데이터 (itineraries_all.csv)
- `페르소나ID`: 페르소나 식별자 (0-5)
- `페르소나명`: 페르소나 이름
- `일차`: 여행 일차 (1-5)
- `코스ID`: 코스 식별자
- `코스명`: 코스 이름
- `방문순서`: 장소 방문 순서
- `장소유형`: 장소 분류 (관광지, 식당, 쇼핑 등)
- `장소명`: 장소 이름
- `지역구분`: 서울 내 지역 구분

### 경로 데이터 (routes_all_simplified.csv)
- `페르소나ID`: 페르소나 식별자
- `일차`: 여행 일차
- `코스ID`: 코스 식별자
- `구간순서`: 경로 내 순서
- `장소명`: 장소 이름 (식당/카페 표시 포함)
- `위도`: 위도 좌표
- `경도`: 경도 좌표

## 🎯 주요 특징

### 1. 페르소나별 맞춤 설계
- **예산 고려**: 각 페르소나의 예산에 맞는 식당 및 활동 선별
- **관심사 반영**: 쇼핑, 문화, K-컬처 등 페르소나별 관심사 반영
- **체류 기간**: 단기/장기 체류에 따른 코스 구성

### 2. 지역별 다양성
- **강남/강북 균형**: 전통과 현대가 공존하는 서울의 다양한 면모
- **핫플레이스 포함**: 홍대, 성수, 이태원, 안국 등 트렌디한 지역
- **올리브영 필수**: 모든 페르소나에 올리브영 방문 코스 포함

### 3. 식도락 중심
- **미슐랭 가이드**: 고소득 페르소나를 위한 미슐랭 식당
- **블루리본 맛집**: 일반 예산대를 위한 검증된 맛집
- **한식당**: 한국 전통 음식 체험

## 🔧 기술적 특징

### 좌표 시스템
- **위도/경도**: WGS84 좌표계 사용
- **지오코딩**: OpenStreetMap Nominatim API 활용
- **수동 매핑**: 모호한 장소명에 대한 정확한 좌표 매핑

### 데이터 검증
- **좌표 유효성**: 서울 지역 내 좌표 검증
- **장소명 정확성**: 실제 운영 중인 장소명 확인
- **일관성 검사**: 페르소나별 데이터 일관성 유지

## ⚠️ 주의사항

### API 연동 필요
현재 좌표 데이터는 OpenStreetMap을 통해 수집되었으나, 정확한 경로 계산과 실시간 정보를 위해서는 다음 API 연동이 권장됩니다:

1. **카카오맵 API**
   - 정확한 한국 내 좌표
   - 실시간 교통 정보
   - 경로 및 소요시간 계산

### 데이터 업데이트
- **영업 상태**: 식당/카페 영업 상태는 변동될 수 있음
- **좌표 정확성**: 건물 리모델링 등으로 인한 주소 변경 가능
- **정기 검증**: 분기별 데이터 유효성 검사 권장

### 스크립트별 상세 기능

#### `split_persona_routes.py` - 페르소나별 파일 분할
- **입력**: `routes_all_simplified.csv` (통합 경로 데이터)
- **출력**: `routes/persona_X_*.csv` (페르소나별 개별 파일)
- **기능**:
  - 페르소나ID별로 데이터 분할
  - 각 페르소나의 고유한 여행 코스 데이터 추출
  - 데이터 일관성 검증 및 파일 구조 확인
  - 자동 정렬 (페르소나ID, 일차, 코스ID, 구간순서)

#### `validate_current_routes.py` - 현재 데이터 검증
- **입력**: `routes_all_simplified.csv` 및 페르소나별 파일들
- **검증 항목**:
  - 좌표 누락 장소 식별 및 상세 리포트
  - 서울 지역 범위 내 좌표 확인 (위도: 37.4-37.7, 경도: 126.7-127.2)
  - 페르소나별 파일 구조 및 데이터 완성도 검사
- **출력**: 검증 결과 요약 및 문제점 상세 리포트

#### `analyze_routes_data.py` - 데이터 분석 및 통계
- **입력**: `routes_all_simplified.csv` 및 페르소나별 파일들
- **분석 항목**:
  - 페르소나별 장소 수, 코스 수 등 통계 분석
  - 지역별 분포 및 장소 유형 분석
  - 데이터 품질 및 완성도 평가
- **출력**: 상세 통계 리포트 및 데이터 품질 평가

#### `test_current_api.py` - API 연결 테스트
- **기능**: API 키 유효성 및 연결 상태 확인
- **테스트 항목**:
  - 카카오맵 API 키워드 검색
  - OpenStreetMap 지오코딩
- **결과**: API 사용 가능 여부 및 대안 제시

#### `update_routes_with_sort.py` - 데이터 업데이트 및 정렬
- **입력**: `routes_all_simplified.csv` (수정할 데이터)
- **기능**:
  - 데이터 수정 및 업데이트
  - 페르소나ID, 일차, 코스ID, 구간순서 기준 자동 정렬
  - 페르소나별 파일 자동 재생성
- **출력**: 업데이트된 `routes_all_simplified.csv` 및 페르소나별 파일들
